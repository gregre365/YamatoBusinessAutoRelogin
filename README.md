# B2クラウド自動再ログイン

> B2クラウドのセッションを維持して、無操作によるログアウトを防ぐ Chrome 拡張機能

B2クラウドは、60分間操作しないとログアウトします。荷造りをして戻ってくる間に切れてしまう長さです。

## 機能

- **セッションの維持** — B2クラウドのタブを開いているあいだ、ログアウトしません。設定は不要です
- **自動再ログイン**（任意） — セッションが切れたときに、保存したログイン情報でログインし直します

## インストール

[Chrome ウェブストア](https://chrome.google.com/webstore/detail/mcjifnlpkbnkccdnnhplfdfocohdkjgg)から「Chrome に追加」を選びます。セッションの維持は、これだけで動きます。

自動再ログインも使う場合は、インストール直後に開く設定画面にログイン情報を入力して保存してください。あとから変更するときは、`chrome://extensions` → 本拡張の「詳細」→「拡張機能のオプション」を開きます。

## 設定

| 項目 | 必須 | 形式 |
|---|---|---|
| 自動的にログインする | — | 有効／無効。無効にすると以下は保存しません |
| お客様コード | 必須 | 半角数字 9〜12桁 |
| お客様コード枝番 | 任意 | 3桁 |
| パスワード | 必須 | 半角英数字 8〜12文字 |
| 個人ユーザーID | 任意 | 半角英数字 6〜20文字 |

お客様コードとパスワードが両方そろっているときだけ、自動ログインします。

## 使ってよい環境

> [!WARNING]
> 共用PCや、他人が触れる場所のPCでは使わないでください。
> この拡張を入れると、席を外してもログアウトしません。

ログインしたままの画面では、お届け先マスタ（氏名・住所・電話番号）が見えます。送り状も発行できます。発行した運賃はお客様コードに請求されます。

自動ログインを有効にしている場合は、さらに、セッションが切れたあとでも画面に触れた人の操作でログインし直してしまいます。

席を外すときは、OS の画面ロックを使ってください（Windows なら <kbd>Win</kbd>+<kbd>L</kbd>）。拡張機能側にロック画面を作っても、拡張を無効にすれば外れます。実際に守れるのは OS のロックだけです。

## 仕組み

セッションの残り時間は `UID` クッキーの有効期限として読めます。これを5分おきに確認し、失効の15分前になったら次のリクエストを1回だけ送ります。

```
GET /b2/p/_system_date
```

送り状の発行画面でも使われている問い合わせで、応答は90バイトほどです。読み取りだけで、書き込みも画面遷移もありません。操作中に実行されても表示は変わりません。通信は1時間に1〜2回です。

セッションが既に切れているときは、何もしません。ログイン画面に飛ばされたあとは、自動再ログインが引き受けます。

> [!NOTE]
> B2クラウドのタブを長時間バックグラウンドに置くと、Chrome のメモリセーバーがタブを凍結・破棄することがあります。こうなると拡張機能も止まり、セッションは60分で切れます。
>
> 常に維持したい場合は、Chrome の設定 →「パフォーマンス」→「常にアクティブにするサイト」に `newb2web.kuronekoyamato.co.jp` を追加してください。

## 動作するページ

次のページでだけ動きます。ほかのページには関与しません。

| ページ | 動作 |
|---|---|
| B2クラウドの各画面 | 失効が近いとき、延長のリクエストを1回送る |
| `newb2web` のシステムエラー画面 | ログインボタンを押す |
| `bmypage` のログアウト画面 | 送信ボタンを押す |
| ヤマトビジネスメンバーズのログイン画面 | 保存した情報を入力してログインする |
| `bmypage` のその他の画面 | 「ログイン画面へ」のリンクがあれば押す |

## 権限

| 権限 | 用途 |
|---|---|
| `storage` | ログイン情報を端末内に保存する |
| ホスト権限 | セッションの維持、ログアウトの検知、ログインフォームへの入力。対象は `newb2web.kuronekoyamato.co.jp` と `bmypage.kuronekoyamato.co.jp` だけ |

外部スクリプトの読み込みや `eval` はしていません。JavaScript はすべてパッケージに同梱しています。

## データの取り扱い

入力した情報は `chrome.storage.local` に保存します。**拡張機能の作者や第三者のサーバーへ送ることは一切ありません。**送信先はヤマトビジネスメンバーズのログイン画面だけで、自動ログインのときに入力欄へ記入して送信します。手で入力する場合と同じ経路です。

ただし暗号化はしていません。無人でログインする以上、拡張機能自身がパスワードを平文に戻せる必要があり、鍵を同じ端末に置いた暗号化は気休めにしかならないからです。Chrome のプロファイルを読める人には見えると考えてください。

自動ログインを無効にすれば、ログイン情報は保存しません。セッションの維持だけを使うなら、この拡張が預かるものはありません。

## 開発

ビルドは不要です。`chrome://extensions` でデベロッパーモードを有効にし、「パッケージ化されていない拡張機能を読み込む」でこのディレクトリを指定します。

ヤマト側の画面構成が変わると動かなくなります。直す場所は `contentScript.js` の、URL の判定と要素の取得です。
