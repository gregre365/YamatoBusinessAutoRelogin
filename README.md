# B2クラウド自動再ログイン

ヤマトビジネスメンバーズ（B2クラウド）が無操作でセッションタイムアウトしたとき、自動的に再ログインする Chrome 拡張機能です。

## 使い方

1. **[Chrome ウェブストアからインストール](https://chrome.google.com/webstore/detail/mcjifnlpkbnkccdnnhplfdfocohdkjgg)** して「Chrome に追加」
2. インストール直後に開く設定画面に、ログイン情報を入力して「保存」
3. 以降は、タイムアウトしても自動でログインし直します

必要な操作はこれだけです。

設定をあとから変更する場合は、`chrome://extensions` を開き、本拡張の「詳細」から「拡張機能のオプション」を選んでください。

### 設定項目

| 項目 | 必須 | 形式 |
|---|---|---|
| お客様コード | 必須 | 半角数字 9〜12桁 |
| お客様コード枝番 | 任意 | 3桁 |
| パスワード | 必須 | 半角英数字 8〜12文字 |
| 個人ユーザーID | 任意 | 半角英数字 6〜20文字 |

お客様コードとパスワードの両方が保存されている場合にのみ、自動ログインを実行します。

## 動作するページ

次のページでのみ動作します。それ以外のページには一切関与しません。

| ページ | 動作 |
|---|---|
| `newb2web` のシステムエラー画面 | ログインボタンを押す |
| `bmypage` のログアウト画面 | 送信ボタンを押す |
| ヤマトビジネスメンバーズのログイン画面 | 保存済みの情報を入力してログインする |
| `bmypage` のその他の画面 | 「ログイン画面へ」のリンクがあれば押す |

## データの取り扱い

入力した情報は `chrome.storage.local` に保存され、**端末内にのみ保持されます**。外部のサーバーへ送信することは一切ありません。

ただし**暗号化はしていません**。自動でログインする以上、拡張機能が無人でパスワードを平文に戻せる必要があり、鍵を同じ場所に置いた暗号化は防御になりません。そのため、Chrome のプロファイルディレクトリを読める人（同じ PC を使える人、プロファイルをバックアップした先など）からは参照できます。共用の PC では、この点を承知のうえで利用してください。

## 権限

| 権限 | 用途 |
|---|---|
| `storage` | ログイン情報を端末内に保存するため |
| ホスト権限 | ログアウトの検知とログインフォームへの入力のため。対象は `newb2web.kuronekoyamato.co.jp` と `bmypage.kuronekoyamato.co.jp` の該当ページに限定 |

外部スクリプトの読み込みや `eval` は行っていません。JavaScript はすべてパッケージに同梱しています。

## 開発

ビルドは不要です。`chrome://extensions` でデベロッパーモードを有効にし、「パッケージ化されていない拡張機能を読み込む」からこのリポジトリのディレクトリを指定します。

ヤマト側のページ構造が変わると動かなくなります。直すのは `contentScript.js` の、URL の判定と要素の取得部分です。
